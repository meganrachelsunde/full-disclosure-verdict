# CLAUDE.md — Full Disclosure Verdict

This is an independent clean-room project. It was created from scratch
and must be treated as fully standalone.

## Isolation

- Never access, search, import, copy, or reuse code, configuration, or
  content from any other local repository or project.
- Never access or reference any deleted repository or deleted Claude
  session.
- Never create AGENTS.md in this project.
- Never add hooks, agents, skills, plugins, or MCP servers without
  Megan's explicit approval first.

## Data and secrets

- Never commit secrets, API keys, or credentials.
- Never commit real patient information or real case records.
- Document-upload functionality does not exist yet. It must not be
  added until a security and privacy architecture has been reviewed
  and explicitly approved.

## Content integrity

- Evidence, inference, and professional conclusions must always be
  kept in clearly separate categories. Inventory, chronology, gap, and
  contradiction entries are observations tied to source documents —
  never opinions, diagnoses, or conclusions.
- This product does not provide legal advice, diagnoses,
  standard-of-care opinions, causation opinions, damages calculations,
  or case-merit conclusions. Do not add features or copy that blur
  this line.

## External actions

- Every action with external effect (pushing code, creating a GitHub
  repository, deploying, publishing, or creating any other external
  resource) requires explicit human approval before it happens.
- Do not push, deploy, publish, or create external resources on your
  own initiative.
